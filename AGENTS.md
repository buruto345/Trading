# Research constraints

All work stays inside this project. No credentials, trading accounts, orders or live execution.
Historical files must retain their public provenance. Synthetic candles only in tests/data/synthetic.
Confirmed model rules are in docs/MODEL_SPECIFICATION.md. Research conventions are not confirmed rules.
Do not tune assumptions using out-of-sample results. Preserve chronological splits and censored outcomes.
Run pytest and the pipeline, reconcile report counts with stored observations, then run offline browser QA.
Communicate results and limitations in Vietnamese. Never assert profitability from historical significance.
