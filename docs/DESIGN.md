# Design read

Artifact: offline quantitative dashboard, greenfield. Audience: Vietnamese-speaking researcher.
Visual language: institutional data-first, editorial headings and compact analytical tables.
Variance 3 / motion 1 / density 8 / asset dependence 2 / brand fidelity 2.
Purpose: lead with actual uncertainty and sample size; laptop reading, restrained tone.
18 sections use sidebar navigation, progressive methodology disclosure and wide charts.

Palette: paper #f4f3ef, panel #ffffff, ink #182a2b, muted #647574, accent #146f64,
negative #b54d45, rule #dce2dd. Dark: background #142324, panels #1d3030, text #e8eeea.
Heading: Cambria (Vietnamese glyph coverage verified in browser); body: Segoe UI; numerical labels: Consolas. All locally available fallback fonts.
Spacing multiples of 8px, controls radius4px, panels radius8px, no decorative shadows.
Motion: none except control feedback. Chart color has direction/outcome meaning.
No external font, image, script or stylesheet dependency in final HTML.
User explicitly delegated routine design decisions; no confirmation checkpoint required.
